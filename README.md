## 🧬 About Us

**Team Cyfer Trace** is a team of B.Tech CSIT (Cyber Security) students, Class of 2028, at **Symbiosis Skills & Professional University, Pune, India**.

We compete in **hackathons and CTF challenges** under this name, and we use this organization to publish the security tools, detection systems, and research projects we build along the way.

Our focus areas include threat intelligence, incident response, network security, cyber deception, AI-driven security automation, and offensive security research.
